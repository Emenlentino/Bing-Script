# Bing-Script

## Bot Features

- **Bypass Cooldown Limits**: Efficiently bypass Bing search cooldown restrictions to optimize farming.
- **Full Functionality**: Seamlessly operate through web browsers and Python environments.
- **Cross-Platform Compatibility**: Utilize mobile browsers and automation tools like Termux and Selenium to run scripts and manage accounts effectively.
- **Customizable User-Agents**: Tailor user-agents for various devices to ensure smooth operation.

## Getting Started

### Prerequisites
- Python 3.8 or higher
- Pip (Python package manager)
- Recommended: Virtual Environment for dependencies

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Emenlentino/Bing-Script.git
   cd Bing-Script
   ```

2. Set up a virtual environment (optional but recommended):
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # For Windows: venv\Scripts\activate
   ```

3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

### Running the Bot
1. Start the bot by executing the main script:
   ```bash
   python index.py
   ```
2. Follow the on-screen menu to select desired actions.

## Troubleshooting

- **Dependency Issues**: Ensure all packages listed in `requirements.txt` are installed.
- **File Not Found Errors**: Check the folder structure and paths for files like `donate.md` or `accounts.json`.
- **Permission Issues**: Run scripts with appropriate permissions or ensure necessary directories are writable.
